# Vikas Dubey — Portfolio

**Live site:** [https://vikas-dubey-portfolio-800.netlify.app](https://vikas-dubey-portfolio-800.netlify.app)

Personal Vite + React portfolio for Senior React Native Engineer Vikas Dubey.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
